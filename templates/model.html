Architecture

A three-block convolutional network

Each convolution block learns more abstract features: the first finds colour edges and stain boundaries, the second finds nuclei shapes, and the third finds how cells are arranged, which is what separates invasive carcinoma from normal ducts.

Training

How it was trained

Loss

Binary cross-entropy:
L = −[y·log p + (1−y)·log(1−p)]

Optimiser

Adam, learning rate 0.001, halved every 4 epochs. Early stopping on validation AUC (patience 4); best epoch: {{ m.best_epoch or '—' }}.

Augmentation

Random horizontal/vertical flips and 90° rotations. Tissue has no "up", so these create valid new examples.

Patient-level split

70 / 15 / 15 split by patient, not by image. Patches from one patient never appear in both train and test, so there is no data leakage.

Initialisation

He-normal weights (suited to ReLU), zero biases, batch size 64.

Built from scratch

Every layer's forward and backward pass is written in NumPy (bcnet/npcnn.py) and gradient-checked against numerical derivatives.

Explainability

Grad-CAM and region scanning

Grad-CAM (single patch)

We back-propagate the malignancy score to the last convolution layer, average the gradient of each of its 64 feature maps to get an importance weight, and sum the weighted maps. After a ReLU this gives a 12×12 heatmap of the regions that raised the score, which is upsampled over the image.

cam = ReLU( Σₖ mean(∂y/∂Aₖ) · Aₖ )

Region scan (larger images)

For an image larger than a patch, a 50×50 window slides across the tissue. Blank background tiles are skipped and every tissue tile is classified. The image score is the mean of the top 10% most suspicious tiles, so one small tumour focus is not averaged away by healthy tissue.
